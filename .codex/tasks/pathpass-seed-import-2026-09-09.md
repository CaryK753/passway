# PathPass 种子导入任务

## 目标

将 `https://pathpass.vercel.app/countries/*` 的公开国家页完整采集为 Pathway Vault 中可审计的待核验来源卡，为后续逐条拆分路径实体和官方来源复核提供稳定输入。

## 范围

- In：国家页 URL 清单、抓取元数据、页面摘要、路径名称、PathPass 陈述和页面列出的官方链接候选。
- Out：将 PathPass 陈述标记为已核验；从二级页面自动推导法律事实；自动创建已发布路径实体；实施应用代码。

## 状态

- [x] 发现 41 个 `/countries/*` 页面。
- [x] 抓取并写入全部来源卡（41/41）。
- [x] 生成导入清单和覆盖统计。
- [x] 校验每个导入页面的元数据和链接（41 张来源卡、252 个页面路径条目）。
- [ ] 选择首批页面进行逐条官方复核与实体化。

## 验收条件

1. 每个国家页有独立 Markdown 来源卡，包含 PathPass URL、抓取日期和二级来源等级。
2. 每张卡完整保留路径条目及页面提供的外链候选。
3. 所有导入内容均为 `draft` / `in-review`，不得作为确定性 AI 依据。
4. 导入清单能报告成功、失败和待重试页面。
