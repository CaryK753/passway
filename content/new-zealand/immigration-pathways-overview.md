# 新西兰移民与长期居留路径总览

> 本文核验于 2026-09-09。新西兰职业、工资、雇主认证和居民签证规则会调整；具体资格以 Immigration New Zealand 当前页面为准。

## 主要路径

### 技术移民居民签证

[Skilled Migrant Category Resident Visa](https://www.immigration.govt.nz/visas/skilled-migrant-category-resident-visa/)要求申请人符合年龄、英语、健康和品格要求，并拥有或获得认证雇主的技术职位，同时满足当时适用的技术移民路径。通常先提交意向书，收到邀请后才能申请；满足基础条件不等于必然获邀。

### 绿名单与工作转居民

部分紧缺职业可能通过直接居民或工作一段时间后申请居民身份的路线处理。职业名称、资格、注册、工资及工作期限均需对照当期 Green List 具体条目，不能只凭行业属于紧缺领域作判断。

### 认证雇主工作签证

[Accredited Employer Work Visa](https://www.immigration.govt.nz/visas/accredited-employer-work-visa/)通常需要认证雇主提供符合要求的工作。签证条件与雇主和职位相关；能否支持家属、停留多久、以及是否通往居民身份，需要按职位和收入等条件分别核对。

### 家庭

新西兰公民、居民以及部分临时签证持有人可在特定条件下支持伴侣、子女或父母申请。关系真实性、共同生活、担保资格及家属签证权利按类别不同；例如伴侣居民路径应从[新西兰人伴侣居民签证](https://www.immigration.govt.nz/visas/partner-of-a-new-zealander-resident-visa/)核对，再按实际关系选择类别。

### 学习后衔接

学生签证与毕业后工作签证的资格取决于教育机构、课程、学习方式及申请时间。[官方学习入口](https://www.immigration.govt.nz/study/)用于确认学习与工作条件。毕业后工作许可并不保证能够满足技术居民签证或绿名单要求。

### 投资与经营

新西兰提供面向投资者或实际经营者的不同路线，投资类型、金额、经营参与、停留时间和居民身份阶段不同。[投资与经商签证比较](https://www.immigration.govt.nz/work/visas-for-investing-and-doing-business-in-new-zealand/)应作为当前入口，旧 Investor 或 Entrepreneur 项目页面可能只适用于历史申请人。

## 建议的筛选顺序

1. 从[签证查找器](https://www.immigration.govt.nz/visas/)确认当前开放类别。
2. 有工作时核对雇主认证、职位、职业注册、工资和签证期限。
3. 单独检查该职位是否满足技术居民或绿名单的精确条件。
4. 评估家属权利及从 Resident Visa 到 Permanent Resident Visa 的后续条件。

## 常见误区

- AEWV 是工作许可，不自动等于居民签证。
- “绿名单职业”仍需满足该职业条目的全部资格和职位要求。
- Resident Visa 与 Permanent Resident Visa 不是同一个阶段。
- 旧项目仍有网页不代表仍接受新申请。
