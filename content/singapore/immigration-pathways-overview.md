# 新加坡工作、永久居民与入籍路径总览

> 本文核验于 2026-09-09。新加坡工作准证与永久居民申请是不同制度；持有准证或达到公开条件不代表 ICA 必须批准永久居民身份。

## 主要路径

### Employment Pass

[Employment Pass](https://www.mom.gov.sg/passes-and-permits/employment-pass)面向符合条件的外国专业人士、经理和高管，通常由新加坡雇主或指定代理申请。申请会考察固定月薪及其他资格，部分申请还需要通过互补专才评估框架。准证与就业关系相关，换雇主通常需要新申请。

### S Pass 及其他工作准证

[S Pass](https://www.mom.gov.sg/passes-and-permits/s-pass)面向符合技能和薪资条件的人员，并受雇主配额及征费等制度影响。其他行业或活动可能适用 Work Permit、Personalised Employment Pass 或 Overseas Networks & Expertise Pass。应从 MOM 的[准证总表](https://www.mom.gov.sg/passes-and-permits)确认当前类别。

### EntrePass

[EntrePass](https://www.mom.gov.sg/passes-and-permits/entrepass)面向符合条件、具风险投资支持或创新技术特征的创业者。注册公司或成为股东本身不足以获得准证；企业类型、申请人背景、续签业务指标和家属资格均需逐项核对。

### 家属

部分工作准证持有人在满足条件时可为配偶或子女申请 Dependant's Pass，或为其他特定家庭成员申请 Long-Term Visit Pass。家属准证不应被理解为自动、无限制的工作许可；拟工作时要查看 MOM 的现行工作安排。

### 永久居民

ICA 的[永久居民申请入口](https://www.ica.gov.sg/reside/PR/apply)列出可申请群体，包括部分新加坡公民或永久居民的家庭成员、Employment Pass 或 S Pass 持有人、学生及外国投资者。ICA 会综合评估申请；符合可申请类别只表示可以递交，不构成获批保证。

### 入籍

永久居民在满足对应年龄、居住及其他条件时可查看[新加坡公民申请](https://www.ica.gov.sg/reside/citizenship/apply)。新加坡对双重国籍有限制，取得或放弃国籍涉及重大法律后果，应在决定前核对 ICA 最新说明和原国籍法律。

## 建议的筛选顺序

1. 先确定需要的是工作准证、家属居留还是永久居民。
2. 工作路线核对雇主资格、薪资、评估框架、配额和换雇主规则。
3. 永久居民申请单独准备家庭、经济贡献、教育和居住等证明。
4. 入籍前评估国籍、兵役及家庭成员的长期影响。

## 常见误区

- EP 或 S Pass 没有自动转 PR 的固定年限。
- 公司注册不是 EntrePass 批准的充分条件。
- 可以申请 PR 不等于满足一套公开打分线。
- PR、再入境许可和公民身份具有不同权利与维持要求。
