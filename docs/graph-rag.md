# 检索、Wiki 与图谱架构

## 状态

本文取代早期自建 Graph RAG 设计。当前决策见 [ADR-0004](adr/0004-github-content-and-weknora-derived-knowledge.md)。

## 能力归属

WeKnora 负责文档解析、分块、向量与关键词检索、问答编排、Auto-Wiki 和图谱派生。Passway 不在 MVP 阶段复制这些通用基础设施，而是在 Adapter 后使用它们。

人工文章仍是事实源。任何生成页面、摘要、实体或关系都不能因为进入图谱而自动成为已核验政策。

## 两类图谱

| 图谱 | 数据来源 | 主要用途 | MVP |
| --- | --- | --- | --- |
| Wiki 页面链接图 | Auto-Wiki 页面链接和反向链接 | 浏览、发现相关文章、解释页面关系 | 展示 |
| 实体关系知识图谱 | 模型抽取的实体和关系 | 检索增强、研究辅助 | 评测后再公开 |

两者必须使用不同标签、图例和说明。页面链接不能被描述为法律上的资格、替代或身份转换关系。

## 问答流程

```text
用户背景与问题
→ Passway 服务端校验、限流和最小化
→ WeKnora knowledge chat / agent chat
→ 流式事件与引用
→ Passway 引用映射、状态检查和安全后处理
→ 回答 + 人工文章 + 官方来源
```

核心政策结论必须最终回链到人工文章和官方来源。只引用 Auto-Wiki 页面不足以证明结论。

## 前端读取

Passway 服务端 Adapter 读取 Wiki 索引、页面、链接图和问答。API Key 不进入浏览器。对于图片与附件，服务端必须处理 WeKnora 的 `resource://` 引用或使用经过安全评估的资源 URL 模式。

大图不能一次性发送和渲染。图谱默认按当前页面加载邻居，限制节点数并支持逐步展开。

## 降级

- WeKnora 不可用：继续展示人工文章，隐藏或标记 Wiki、图谱和问答不可用。
- Wiki 未更新：展示最近成功版本及其 source commit，不冒充最新。
- 引用无法映射：回答降级为不确定，不能移除引用警告后继续输出。
- 实体图质量不足：只保留页面链接图和传统混合检索。

## 评测

PoC 对全文/混合检索、知识问答、Wiki 更新和两类图谱分别评测。不能用“图谱存在”代替召回质量，也不能用回答流畅度代替来源忠实度。
