# 产品与范围

## 产品定义

Passway 是公开、可审计、可版本化的全球移民信息服务。它将人工核验文章与 WeKnora 生成的 Wiki、关系图和问答组合在同一阅读环境中。

用户可以：

- 按国家、地区、主题和目标身份阅读人工文章；
- 查看 WeKnora 从文章生成的 Wiki 页面、反向链接和关系图；
- 在标签页或分屏中对照文章、来源和 Wiki；
- 输入个人背景，在不登录的情况下获得带引用的资料整理；
- 查看文章的核验日期、适用范围、官方依据和生成内容标识。

## 首版能力

1. 普通 Markdown 文章阅读、目录、搜索与筛选。
2. WeKnora Auto-Wiki 页面、索引、反向链接和页面链接图。
3. 多主题、标签页、双栏分屏和移动端阅读。
4. 结构化个人背景输入与免登录问答。
5. WeKnora 流式回答、原文引用和相关文章联动。
6. 页面级核验状态、适用时间、来源和纠错入口。
7. GitHub 到 WeKnora 的幂等增量同步、验证与回滚。

## 人工与生成内容边界

- 人工文章是政策事实入口，必须由作者和复核流程负责。
- Auto-Wiki 是从文章生成的导航与解释层，不自动获得 `verified` 状态。
- Wiki 页面链接图表示生成页面之间的链接，不等同于法律关系。
- 实体关系知识图谱是检索增强数据，不直接作为确定性政策结论。
- 问答必须引用人工文章或其原始来源，不能仅以生成 Wiki 互相引用证明事实。

## 明确不做

- 不提供法律意见、审批承诺或获签概率。
- 不代填或自动提交政府表格。
- 不保存护照号和证件扫描件等高敏感材料。
- 不建设在线 CMS 或让 WeKnora 反向改写 GitHub 文章。
- 首版不自建向量数据库、通用 Graph RAG 框架或复杂多 Agent 系统。
- 不依赖 LLM 自身记忆补全缺失或过期政策。

## 质量原则

- 所有已发布文章具备稳定 ID、法域、核验日期和官方来源。
- 生成内容在 UI 中始终可辨识。
- 同步状态可追溯到 Git commit 和 WeKnora knowledge ID。
- WeKnora 或 AI 不可用时，人工文章仍可阅读。
- 过期、冲突或信息不足时明确降级，不猜测。

## 公益与可持续性

静态文章必须在 AI 不可用时完整工作。免登录接口需要限流、匿名配额、输入输出上限和全局预算熔断。优先复用 WeKnora 成熟能力，避免把有限维护资源投入重复基础设施。
