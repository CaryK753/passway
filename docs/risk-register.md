# 风险登记册

## 1. 评估方法

概率和影响使用 `低 / 中 / 高`。风险状态使用 `open / monitoring / mitigated / accepted`。本登记册不替代具体安全评审或法律意见。

## 3. Phase 0 必须关闭或接受的风险

进入内容 spike 前，需要为以下风险指定负责人和具体验证：

- R-04：claim 级来源模型；
- R-07/R-08：schema 粒度；
- R-13/R-14：法律边界和翻译复核；
- R-16：第二复核机制。

进入匿名 AI 前，需要关闭或显式接受：

- R-02/R-03：检索污染和无依据结论；
- R-09/R-10：派生更新与图谱语义；
- R-11/R-12：滥用与隐私；
- R-17：免费基础设施降级；
- R-19：提示注入；
- R-20：评测有效性。

## 4. 维护规则

- 每个阶段出口评审更新概率、影响、状态和证据链接。
- 已缓解不等于删除，回归时重新打开。
- 新风险先登记，再决定是否形成 ADR、任务或发布阻断项。
- 严重线上错误必须关联到风险、根因和新增回归测试。
